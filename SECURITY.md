# Política de Segurança (Security Policy)

## Versões com Suporte (Supported Versions)

Apenas a versão estável mais recente da linha `0.1.x` recebe atualizações e correções de segurança ativas.

| Versão | Suporte de Segurança |
| ------ | -------------------- |
| 0.1.x  | :white_check_mark:   |
| < 0.1  | :x:                  |

## Como Reportar uma Vulnerabilidade (Reporting a Vulnerability)

Agradecemos o esforço responsável de pesquisadores e membros da comunidade em reportar potenciais vulnerabilidades de segurança.

**Por favor, NÃO abra issues públicas no GitHub para relatar vulnerabilidades ou vazamentos.**

Para relatar uma vulnerabilidade com segurança:
1. Acesse o canal oficial de relatórios de vulnerabilidade privada:  
   👉 **[Abrir Notificação de Vulnerabilidade Privada](https://github.com/raalarcon9705/PingouNota/security/advisories/new)**
2. Descreva os detalhes técnicos da vulnerabilidade, etapas de reprodução e possíveis impactos observados.

### Diretrizes de Divulgação Segura (Safe Reporting Guidelines)

- **Nunca inclua dados confidenciais:** não inclua tokens de API reais (como chaves de API da Adaflow), credenciais, cookies de sessão, CPFs/CNPJs reais de clientes ou comprovantes bancários com dados de terceiros.
- Utilize sempre dados sintéticos ou mascarados em exemplos de reprodução e capturas de tela.
- Dê tempo razoável para a equipe analisar e lançar correções antes de qualquer divulgação pública.
