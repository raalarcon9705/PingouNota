Mais segurança para a sua conta

A segurança da sua conta é algo muito importante para nós, pensando nisso, agora temos mais um passo de verificação para ações importantes dentro do sistema.
Funciona de maneira bem simples:

  1. Após realizar eventos que consideramos críticos, deixaremos o evento como pendente até que um código seja informado.
  2. Vá até o topo da página e solicite o código que será enviado por SMS para o seu celular de autorizações (por padrão o mesmo utilizado para ativar a conta).
  3. Insira o código no campo onde é solicitado.
  4. Pronto, você validou seus eventos! Caso fique com dúvidas sobre quais são os eventos críticos e como alterar o seu celular para autorizações confira a nossa Central de Ajuda.
